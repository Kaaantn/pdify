# 📄 Pdify — Word Gibi Düzenle, Temiz Çıktı Al

Herhangi bir PDF'i yükleyin; içindeki her metni, her görseli ve metadata'yı
doğrudan düzenleyin. Sonuç, bir PDF editöründen geçmiş gibi değil, sanki Word'den
yeni export edilmiş kadar temiz görünür. Tamamen ücretsiz, kayıt gerektirmez,
dosyalarınız cihazınızdan hiç çıkmaz.

## ✨ Öne Çıkanlar

- ✍️ **Gerçek içerik düzenleme** — metne tıkla, yaz; görseli taşı/değiştir/sil
- 🏷️ **Metadata düzenleme** — Başlık, Yazar, Konu, Anahtar Kelimeler
- 🧼 **Temiz çıktı** — "kapla ve yeniden çiz" mimarisiyle düzenleme izi bırakmaz
- 🔒 **%100 gizlilik** — dosyalar hiçbir zaman sunucuya yüklenmez, her şey tarayıcıda işlenir
- 🆓 **Tamamen ücretsiz** — limit yok, kayıt yok, premium katman yok

## 🧱 Teknoloji

Next.js 16 · TypeScript · Tailwind CSS · pdf-lib · pdf.js · Vercel

## 🚀 Yerel Geliştirme

```bash
git clone https://github.com/<kullanici-adi>/<repo-adi>.git
cd <repo-adi>
npm install
npm run dev
```

http://localhost:3000 adresini açın.

## 🔐 Gizlilik

Bu uygulama yüklediğiniz hiçbir dosyayı bir sunucuya göndermez veya depolamaz.
Tüm işlemler tarayıcınızda gerçekleşir. Detaylar: `/gizlilik`

## ⚠️ Bilinen Sınırlar

Çok karmaşık, çok kolonlu veya gerçek zamanlı "reflow" gerektiren layout'larda
düzenleme kutunun kendi sınırları içinde kalır (tüm sayfa otomatik yeniden
akmaz). Standart iş belgeleri, sözleşmeler, formlar, CV'ler için tasarlanmıştır.
Metin fontları, orijinal gömülü fontun birebir aynısı yerine en yakın standart
fonta (Helvetica, Times, Courier ailesi) eşlenir. Detaylar: `/hakkinda`
